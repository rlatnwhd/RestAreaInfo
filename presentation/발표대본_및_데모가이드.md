# 휴게길 발표 대본 및 시연 가이드

총 9분 50초 예상, 시연 포함.

## 1. 휴게길

[15초] 안녕하세요. 김수종입니다. 휴게길은 이동 경로에 맞춰 휴게소와 졸음쉼터를 찾고, 음식과 시설을 비교하는 공공데이터 기반 웹사이트입니다.

## 2. 운전자는 장소보다 ‘가는 방향의 정보’가 필요합니다

[40초] 휴게소는 반대 방향에 있으면 이용하기 어렵습니다. 음식, 입점 매장, 주차 정보를 여러 곳에서 찾는 번거로움도 있습니다. 경로와 방향을 중심으로 정보를 모으고, 같은 기준으로 비교하도록 설계했습니다.

## 3. 흩어진 공공데이터를 휴게소 단위로 연결했습니다

[45초] 한국도로공사 기준정보, 메뉴, 브랜드 자료와 공공데이터포털의 졸음쉼터, 주차장, 과거 이용량을 연결했습니다. 10월 28일 실제 조회 결과입니다. 카카오 API는 지도 표시, 장소 검색과 자동차 경로에 사용합니다. 주차는 빈자리 수가 아닌 공식 주차면 수입니다. 출처: data.ex.co.kr/openapi, data.go.kr/data/15043710/fileData.do, data.go.kr/data/15043716/fileData.do, data.go.kr/data/15118977/fileData.do, developers.kakao.com, developers.kakaomobility.com.

## 4. 찾기 · 확인하기 · 비교하기로 이어지는 사용 흐름

[50초] 첫째 출발지와 도착지를 검색하면 경로와 관련 고속도로, 해당 방향의 휴게소와 졸음쉼터를 확인합니다. 둘째 상세창에서 음식, 브랜드, 시설, 위치를 확인합니다. 셋째 비교할 휴게소를 담아 같은 음식의 저렴한 쪽과 주차 규모 등을 비교합니다. 방향은 경로와 자료에 기반한 판정이며 실제 진입 가능성을 보증하지는 않습니다.

## 5. 생성형 AI는 개발 보조에 활용했습니다

[45초] 이 프로젝트의 AI 활용은 Codex를 통한 개발 보조입니다. 사용자 입력을 받아 AI가 추천하는 런타임 기능은 구현하지 않았습니다. 실제 요구사항을 전달해 코드와 UI를 수정하고, 실제 API 응답과 테스트로 확인했습니다. 분류 기준이 모호했던 음식 분류는 제거했고, 없는 데이터는 만들어내지 않고 확인 불가로 표시했습니다. 평가표의 사용자 대상 AI 기능은 향후 개선 과제입니다.

## 6. 정보의 우선순위를 정리하고 모바일까지 맞췄습니다

[40초] 왼쪽은 초기 구조를 설명하기 위해 재구성한 와이어프레임입니다. 원본 초기 산출물은 아닙니다. 오른쪽은 현재 앱 화면입니다. 긴 정보를 탭으로 나누고 브랜드 로고, 운영 상태, 기준일을 보여줍니다. 화면 폭이 줄어들면 카드가 자연스럽게 재배치됩니다. 로딩과 오류 상태도 별도로 안내합니다.

## 7. 실제 사용 흐름을 시연하겠습니다

[150초] 발표 전 배포 URL을 이 슬라이드에 입력하고 실제 접속을 확인하세요. 시연 1: 출발지 서울만남의광장휴게소와 도착지 안성시청을 검색해 장소를 선택한 뒤 경로를 찾습니다(50초). 시연 2: 휴게소 상세에서 메뉴, 브랜드 운영시간, 주차와 지도 확인(40초). 시연 3: 두 휴게소를 비교해 같은 음식 가격과 주차면 수 확인(40초). 시연 4: 졸음쉼터 위치 확인 및 처음 화면으로 복귀(20초). 장애 시 이 자료의 실제 화면 캡처로 설명합니다. 배포 URL은 미전달 상태이며 현재 배포 여부를 검증하지 않았습니다.

## 8. 화면과 API를 분리해 운영할 수 있도록 구성했습니다

[45초] 프런트엔드는 React 19와 Vite 7, 백엔드는 Node.js 기반 API 중계 서버입니다. 서버에서 한국도로공사, 공공데이터포털, 카카오 REST API를 호출하며 REST 인증키는 서버 환경변수로 관리합니다. 지도 JavaScript 키는 도메인 설정이 필요합니다. 좌표 캐시, 요청 병렬화와 로딩 상태로 초기 표시를 개선했습니다. 이 슬라이드의 배포 완료는 사용자 요청에 따른 배포 후 발표용 문구입니다. 실제 공개 URL 전달과 접속 검증은 아직 필요합니다. 실제 완료 전에는 발표에서 완료 사실로 말하지 마세요.

## 9. 많은 탭보다, 결정에 필요한 정보를 선명하게

[40초] 핵심 가치는 방문할 장소를 결정하기 위한 정보를 한 흐름에 모았다는 점입니다. 같은 음식은 가격을 직접 비교하고, 주차는 등록 면수로 비교합니다. 자료가 없는 항목은 없음과 구분합니다. 주차 실시간 빈자리와 실제 영업 상태는 제공하지 못하며, 경로 인근 판정도 진입 가능성을 보장하지 않습니다. 사용자 대상 AI 기능, 방향 검증 보강과 실사용자 평가가 다음 과제입니다.

## 10. 이동 경로에 맞는 쉼을 더 쉽게

[20초] 휴게길은 공공데이터를 이동 경로라는 맥락으로 연결해, 어디에서 쉴지 선택하는 과정을 돕습니다. 들어주셔서 감사합니다. 질문 받겠습니다. 발표 총 예상 시간 9분 50초이며 시연 2분 30초를 포함합니다.
