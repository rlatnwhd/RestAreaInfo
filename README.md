# 휴게길 — 고속도로 휴게소 통합정보

React + Vite와 Node.js 프록시로 구현한 한국어 반응형 공공데이터 활용 웹사이트입니다. 남색·청록색 안내 화면, 실제 휴게소·음식 검색, 상세정보, 2~3곳 비교, 자동차 경로 및 지도, 과거 통계 차트를 제공합니다. 공식 정부·도로공사 운영 사이트가 아닌 대학 프로젝트입니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```sh
npm install
npm run dev
```

**http://localhost:5173** 으로 접속하세요. 제공받은 지도 JavaScript 키는 이 도메인에서 정상 응답을 확인했습니다. `http://127.0.0.1:5173`이나 다른 포트를 사용할 경우 카카오 개발자 콘솔에 해당 도메인을 별도로 등록해야 합니다.

프런트와 API는 하나의 서버에서 동작합니다. 기존 Vite 서버가 5173을 점유하고 있다면 종료한 후 재실행합니다. 운영 확인은 다음과 같습니다.

```sh
npm run build
npm start
```

`npm run preview`도 운영 빌드와 API를 함께 제공합니다. Vite만 별도로 실행하면 API를 사용할 수 없습니다. 서버는 기본적으로 로컬 루프백 주소에 바인딩합니다.

## 인증 설정

제공받은 인증정보는 로컬 `.env`에 저장했습니다. `.env`는 Git에서 제외하며 실제 키는 문서·코드에 기록하지 않습니다. 다른 환경은 `.env.example`을 복사하여 설정하세요.

| 변수 | 용도 |
| --- | --- |
| `EX_API_KEY` | 한국도로공사 네 API |
| `ODCLOUD_API_KEY` | 공공데이터포털 과거 이용객·통행량 |
| `KAKAO_MAP_JS_KEY` | 지도 JavaScript SDK. 브라우저 공개가 필요한 키 |
| `ROUTE_API_KEY` | 카카오모빌리티 자동차 경로 REST 키 |
| `KAKAO_REST_API_KEY` | 별도 카카오 Local REST 키. 비워두면 ROUTE_API_KEY 사용 |
| `EX_COORDINATE_SYSTEM` | 원본 X/Y 좌표계 공식 확인 후에만 WGS84 설정. 현재 비어 있음 |
| `PORT` | 기본 5173 |

비밀 REST·공공데이터 키를 `VITE_*`에 넣지 마세요. 브라우저에는 지도 JavaScript 키만 전달합니다. 실제 외부 호출은 서버에서 수행하며 고정된 제공기관 URL만 호출합니다. 상위 API 오류 URL이나 키는 클라이언트에 보내지 않습니다.

## 실제 검증 결과

2026-10-13 호출 기준이며 수치는 갱신될 수 있습니다. 샘플 필드와 결합 결과는 [API 검증 JSON](docs/api-verification.json), 상세 판단은 [검증 문서](docs/API_VERIFICATION.md)에 있습니다.

| 데이터 | 조회 결과 |
| --- | --- |
| 휴게소 기준정보 | 203곳 |
| 푸드메뉴 | 7,255건 |
| 브랜드 매장 | 699건 |
| 주유소 편의시설 | 432건 |
| 과거 이용객·차량 통행량 | 207곳 |
| 카카오 장소·자동차 경로 | 실제 검색·경로 응답 확인 |
| 공식 메뉴 주소를 변환한 지도 위치 | 130곳 / 기준정보 203곳 |

HTTP 200이어도 한국도로공사 `code: ERROR` 또는 `list: null`이면 실패로 처리합니다. 기준정보·메뉴·브랜드는 `pageSize`, `count`, `numOfRows`를 확인하여 전체 페이지를 수집하고 건수가 부족하면 완료로 보고하지 않습니다. 성공 응답은 서버 메모리에 10분간 캐시하며 재시작 시 초기화합니다.

## 연결 규칙과 한계

- `stdRestCd`의 정확한 일치가 기본 연결 조건입니다. 중복·누락 코드나 반환 명칭 불일치는 자동 연결에서 제외합니다. 이름만으로 데이터셋을 결합하지 않습니다.
- **카카오 실제 자동차 경로는 표시하지만 경로상 휴게소를 확정하는 기능은 아직 미검증입니다.** 기본 API에는 명시적 진입 방향·접속 도로가 없습니다. 이름의 방향 표기나 일정 거리 조건으로 경로상 휴게소를 판정하지 않습니다. 현재 목록과 마커는 전체 휴게소 자료이며 주행 순서로 검증된 목록이 아닙니다.
- **원본 X/Y는 미검증 상태입니다.** 지도 위치는 공식 코드로 연결된 메뉴의 단일 주소를 카카오 주소 검색으로 변환합니다. 여러 주소 또는 여러 지오코딩 결과가 있으면 제외합니다. 이 위치는 주소 기반이며 정확한 진입로 좌표가 아닙니다. 주소 변환이 확인되지 않은 73곳은 마커를 표시하지 않습니다.
- **주유소 시설은 독립 목록으로 제공합니다.** 실제 샘플에서 휴게소 000001과 주유소 000002처럼 코드가 다릅니다. 이를 이름 유사성으로 병합하지 않습니다. 휴게소 상세에는 같은 코드와 명칭으로 연결 가능한 시설만 표시합니다. `stime/etime`은 원본 구간 값이며 영업시간으로 해석하지 않습니다.
- **통계는 독립 화면입니다.** 확인된 필드는 `1일 이용객수(17년)`과 `1일 차량 통행량(24년)`입니다. 2017년 명/일, 2024년 대/일로 구분합니다. 공통 휴게소 코드가 없어 자동 결합하지 않으며 현재 혼잡도·대기시간으로 표현하지 않습니다.
- 메뉴 가격은 숫자 변환에 성공한 경우에만 표시합니다. 등록 시간·가격·메뉴는 현장 운영 정보와 다를 수 있습니다. 음식 재료로 알레르기 안전 여부를 추론하지 않습니다.
- API 조회 시각과 원본 최종 수정일은 구분합니다.

## 검증 명령

```sh
npm test
node scripts/verify-api.mjs
node scripts/check-dev.mjs
node scripts/browser-check.mjs
```

`verify-api.mjs`는 실제 제공기관을 호출하고 키를 제외한 결과 문서를 저장합니다. `check-dev.mjs`와 브라우저 검증은 개발 서버 실행 후 사용합니다. 브라우저 검증은 설치된 Microsoft Edge와 Playwright를 사용합니다. `CHECK_URL`로 다른 검증 주소를 지정할 수 있습니다. 지도 키의 도메인 등록은 별도로 필요합니다.

브라우저 검증은 실제 데이터·지도, 상세 메뉴, 비교, 장소 검색 및 서울–부산 경로, 음식 검색, 연도 전환, 320/390/768px 페이지 넘침을 확인합니다. 스크린샷은 Git에서 제외되는 `artifacts/`에 저장합니다.

## 구조

```text
server/       서버 전용 인증, 제공기관 호출, 페이지네이션, 코드 결합·정규화
src/services/ 클라이언트 API 요청 및 표시 형식
src/components/ 검색, 지도, 목록, 상세·비교, 메뉴·시설, 통계
src/App.jsx   메뉴 전환 및 전체 화면 상태
src/dashboard.css  공공서비스 스타일 및 반응형 레이아웃
docs/         실제 API 검증 결과
tests/        가격·좌표·코드·시설·통계 정규화 검증
scripts/      실제 API 및 브라우저 검증
```

이 Windows OneDrive 폴더에서 기존 출력 디렉터리 정리 단계가 프로세스를 종료시키는 현상이 있어 `build.emptyOutDir: false`를 사용합니다. `dist/index.html`은 새 해시 파일을 참조하지만 이전 해시 파일이 남을 수 있으므로 실제 배포 패키지를 만들 때 사용하지 않는 과거 파일을 정리하세요.
