# 휴게소 시설·주유소·통계 연결

검증일: 2026-10-16. 현재 기준정보 203곳을 전수 대조했습니다.

| 항목 | 연결된 휴게소 | 연결 기준 |
| --- | ---: | --- |
| 휴게소 편의시설 API | 180 | 표준 휴게소 코드 + 명칭 |
| 별도 주유소 편의시설 | 150 | 노선 코드·노선명 + 방향을 보존한 명칭, 양쪽의 유일성 |
| 과거 이용객·교통량 | 165 | 노선 + 방향을 보존한 명칭, 양쪽의 유일성 |
| 공식 방향 | 172 | 표준 코드 + 명칭 + 노선 코드 |

전체 지점의 연결 결과는 `facility-links-verification.json`에 기록했습니다. 미연결·중복 후보는 합치지 않습니다. 이름만의 매칭, 방향 제거, 유사도 매칭, 주유소 코드의 숫자 증가 규칙은 사용하지 않습니다. 검토한 노선 표기 차이만 `server/area-links.js`에서 처리합니다.

## 시설 자료

- 휴게소 편의시설: 한국도로공사 `restinfo/restConvList`, 1,288건 전체 페이지 수집. 주유소 자료 `restinfo/restOilList`와 범위를 구분합니다.
- 방향·경정비 여부: `business/serviceAreaRoute`, 221건 전체 페이지 수집. 코드와 명칭·노선이 일치한 행만 사용합니다. 방향이 여러 개 등록된 동일 표준 코드는 모두 표시합니다.
- 현황 웹페이지: https://www.ex.co.kr/portal/usefee/selectZoneHugae2.do 의 215행. 공식 시설 코드와 정확한 명칭이 일치하는 행의 휴게소 편의시설과 세차·경정비·화물차 라운지 O/X를 사용합니다. 기준일이 없어 수집 확인일 2026-10-16을 기록했습니다. 주유소 칸의 시설을 휴게소 시설로 옮기지 않습니다.
- 와이파이: https://www.data.go.kr/data/15043713/fileData.do 의 2026-08-04 기준 212행. 가능여부 O/X를 사용합니다.
- 차량 정비: https://www.data.go.kr/data/15043715/fileData.do 의 2026-07-31 기준 226행. 공기압·진공·매트·에어건의 수량이 0일 때 없음, 양수일 때 있음입니다.
- 고속버스 환승: https://www.data.go.kr/data/15043711/fileData.do 의 2026-07-31 기준 8행. 해당 행이 연결된 지점만 있음이며 원문 운영시간을 함께 표시합니다. 파일에 없다는 이유로 없음으로 표시하지 않습니다.

CSV와 공식 웹페이지는 `server/data/`에 출처·기준일·확인일과 함께 공개 데이터 사본을 보관합니다. 실시간 API 응답과 정적 사본의 기준을 구분하며, 파일 사본은 자동 갱신되지 않습니다.

전기차 충전·점자블록·장애인 전용 주차 등 별도 설치 여부를 확인하지 못한 항목은 정보 미상입니다. 이용객 통계의 오래된 장애인 주차면 수를 현재 시설 유무로 바꾸지 않습니다. API 실패, 미등록, 빈 값도 시설 부재로 취급하지 않습니다.

## 방향과 통계의 의미

상세정보의 ‘휴게소 방향’은 공식 방향 필드 또는 명칭에 적힌 방향입니다. 현재 출발지의 실제 경로에서 진입할 수 있는지, 반대편 차로에서 접근할 수 있는지를 검증하는 기능과 구분합니다. 지도 경로상 휴게소를 확정하는 기능은 아직 제공하지 않습니다.

이용객은 2017년 명/일, 차량 통행량은 2024년 대/일로 각각 표시합니다. 원본 통계의 소재지와 명칭을 보여 주며 실시간 혼잡도로 표현하지 않습니다. 공급자별 조회 오류는 다른 탭의 정상 정보를 가리지 않습니다.

검증: `npm test`, `npm run build`, `node scripts/check-facilities-links.mjs`. 임시 5194 포트에서 실제 데이터와 320·390·768·1440px 상세 화면을 확인하고 테스트 서버를 종료합니다.
