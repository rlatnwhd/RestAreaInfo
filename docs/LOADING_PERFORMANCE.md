# 첫 화면 로딩 개선

확인일: 2026-10-28

- 첫 화면 음식 건수는 `/api/menu-count`에서 첫 페이지의 `count`만 읽습니다. 전국 메뉴 목록은 음식 메뉴 페이지에서 필요할 때 조회합니다.
- 전체 목록 수집은 첫 페이지를 공유하고 나머지를 최대 4개 요청으로 병렬 처리합니다. 페이지 순서와 총건수 검증을 유지합니다.
- 확인된 휴게소·졸음쉼터 좌표는 `.cache/locations.json`에 7일 보관합니다. 식별자·명칭·공식 주소·방향이 달라지면 이전 값을 재사용하지 않습니다. 인증키는 저장하지 않습니다.
- `/api/map-points-cached`로 저장된 위치부터 표시한 뒤 `/api/map-points`로 나머지를 조회합니다. 실패한 위치를 임의 좌표로 채우지 않습니다.
- `.cache`는 Git과 Node 서버 감시 대상 밖에 있으며 Vite 감시에서도 제외합니다. 캐시 저장 때문에 서버나 화면이 다시 로딩되지 않습니다.
- 음식 건수·지도 위치 로딩을 각각 표시합니다. 지도 SDK가 준비돼도 위치 조회 중이면 0곳으로 표시하지 않습니다. 오류 시 재시도 버튼을 제공합니다.

실측(로컬 환경의 개별 측정이며 보장 시간 아님): 메뉴 총 7,259건 확인 약 1.2초, 좌표 첫 수집 221/243곳 약 7.3초. 새 프로세스에서 캐시 221곳 조회 약 1.0초, 카카오 위치 요청 0회.

검증: `npm test`, `npm run build`, `node scripts/check-initial-loading.mjs`. 로딩 지연·부분 캐시 표시·조회 실패·재시도·모바일 폭을 확인합니다.
