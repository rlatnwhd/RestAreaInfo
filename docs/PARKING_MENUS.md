# 주차장 연결과 음식 메뉴

확인일: 2026-10-17

## 주차장

한국도로공사 휴게소 주차장 현황 API 215건(2026-07-31 기준)을 우선 사용합니다. `PARKING_API_KEY`를 사용하고 비어 있으면 `ODCLOUD_API_KEY`를 사용합니다. 키는 서버 전용 `.env`에 보관합니다.

- 원본: https://www.data.go.kr/data/15043716/fileData.do
- API: `/15043716/v1/uddi:9938ee7f-21f7-4c51-9912-812750bf1d0f`. 실제 인증 조회 215건 확인. 앱의 `/api/parking`과 휴게소 상세에서 사용하며 10분 동안 캐시합니다.
- 사본: `server/data/parking.json` (출처·다운로드 주소·기준일·확인일 포함). 인증·조회·스키마·전체 페이지 수집 오류가 생기면 이 공식 파일 자료를 사용합니다.
- 연결: `server/parking.js`. 노선과 방향을 보존한 명칭이 양쪽에서 유일하게 일치해야 연결합니다. 이 자료의 검토한 노선명 차이만 별칭으로 처리합니다.
- 현재 목록 243곳 중 204곳 연결. 코드가 없기 때문에 이름만으로 연결하거나 방향을 삭제해 맞추지 않습니다. 누락·빈 수치는 0으로 채우지 않습니다.
- 상세 기본정보와 비교 화면에서 전체·소형·대형·장애인 전용 주차면을 표시합니다. 현재 주차 가능 빈자리나 실시간 혼잡도가 아닙니다.
- API 응답은 다시 조회하지만 현재 연결 경로의 기준일은 2026-07-31입니다. 차기 연도의 공식 데이터가 나오면 경로와 기준일을 함께 갱신해야 합니다. 파일 사본은 자동 갱신되지 않습니다.

## 메뉴

음식명 추정 분류와 표준 메뉴 묶음 및 전국 묶음 비교는 제거했습니다. 원본 메뉴명·설명·가격을 표시하며, 노선 → 방향 → 휴게소 선택 검색과 직접 입력 검색을 제공합니다. 추천·베스트·프리미엄 표시는 API 원본 값을 사용합니다.

비교 화면의 메뉴는 원본 배열을 변경하지 않고 숫자 가격 내림차순으로 정렬합니다. 0원은 유효 가격이며 가격 미상은 끝에 둡니다.

상세정보의 좌표 행과 음식 탭의 중복된 입점 매장 운영시간 목록은 제거했습니다. 입점 브랜드 탭의 실제 매장 시간과 확인된 푸드코트 시간은 각 위치에서 확인할 수 있습니다.

검증: `npm test`, `npm run build`, `node scripts/check-parking-menus.mjs`.
