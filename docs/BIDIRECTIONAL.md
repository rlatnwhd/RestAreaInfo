# 양방향 휴게소

확인일: 2026-10-16. 한국도로공사가 제공한 전국휴게소정보표준데이터 215건(2026-09-17 기준)을 현재 등록 목록 243곳과 대조했습니다.

출처: https://www.data.go.kr/data/15025446/standard.do

양방향은 원본 `도로노선방향` 값이 **양방향**인 행만 사용합니다. 휴게소명(접미사 ‘휴게소’와 공백만 정리)과 실제 도로노선번호가 일치하고 양쪽 후보가 유일해야 연결합니다. 반대 방향의 별도 휴게소, ‘통합’이라는 이름, 빈 방향, 방향 별칭이 두 개 있다는 이유로 양방향을 추정하지 않습니다.

확인된 14곳: 옥천만남, 행담도, 하남드림, 마장, 덕평, 장흥정남진, 처인, 고삼호수, 평택, 남한강, 안산, 내린천, 시흥하늘, 김해금관가야.

원본 방향 사본은 `server/data/road-directions.json`에, 현재 코드와 연결된 결과는 `bidirectional-verification.json`에 기록했습니다. 사본은 자동 갱신되지 않습니다.

양방향 휴게소는 해당 노선의 각 방향 목록에 한 번씩 포함하고, 양방향 전용 필터로도 찾을 수 있습니다. 그래서 방향별 건수를 더한 값은 전체 고유 휴게소 수보다 클 수 있습니다. 공식 방향이 있으면 이름의 괄호보다 우선 사용합니다. 양방향 표기는 상·하행 이용 구분이며 휴게소 내부의 차량 회차 허용 여부를 뜻하지 않습니다.

검증: 자동 테스트 25개, 프로덕션 빌드, 실제 API 14곳 대조, 덕평 양쪽 방향/양방향 필터와 상세 출처, 320·390·768px 화면, 기존 노선·방향 선택 검증.
